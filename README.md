# TechHub E-Commerce

# Run locally
Start Apache in XAMPP and open `http://localhost/TechHub-Ecommerce/checkout.html`. Checkout requires the PHP endpoint; opening the HTML directly will not save orders.

# Features
- Select cart items and adjust quantities with a live total.
- Shipping form with browser validation.
- Cash on delivery and simulated GCash payment.
- Order details appended to `data/orders.json` by PHP.
- Recent order history cached in browser storage.
